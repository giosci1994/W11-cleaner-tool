// features

Diagnostics and safe actions, one step at a time

Every check and action says what it means and what changes. The interface of the app is in Italian for now.

🎮

Gaming

Is Windows set up for games?

  • Game Mode and GPU scheduling
  • Power plan and monitor refresh rate
  • Graphics driver, Game Bar recording
  • Free space, pending reboot
🧠

RAM and drivers

Is the hardware running at full speed?

  • RAM speed vs. rated speed (XMP / EXPO / DOCP)
  • Devices with errors
  • Graphics, network and audio drivers with their date
🩺

Problems and crashes

What went wrong in the last 30 days?

  • Blue screens and sudden shutdowns
  • Hardware errors (WHEA), apps that crash or hang
  • An anonymized report to paste into an AI
🧹

Clean, optimize, debloat & duplicates

Safe maintenance tools with a temporary no-sleep switch.

  • Temp files, browser caches, Windows Update cache, Recycle Bin
  • Reversible startup programs and power plan switching
  • Conservative UWP debloat and duplicate files moved to quarantine
🔒

Preview, undo & no personal data

Every change starts with a before → after preview, an optional restore point (needs administrator rights), JSON history with per-session undo, and 30-day quarantine. Deleted temporary files and the emptied Recycle Bin cannot be restored. Crash reports drop user/PC names; no telemetry or network calls.

📦

One exe, x64 and ARM64

Self-contained: .NET is inside. Starts without admin rights. Built by GitHub Actions, with SHA256 for every file.

// download

Download and verify

Nothing to install. Check the SHA256 before opening the exe.

1

Pick your exe

W11-cleaner-tool-x64.exe for Intel and AMD (almost every PC), W11-cleaner-tool-arm64.exe for Snapdragon.

2

Verify it

Put SHA256SUMS.txt and VERIFY.ps1 in the same folder and run the script below.

3

Open it

The exe is not signed yet: if SmartScreen warns you, choose More info → Run anyway.

powershell -ExecutionPolicy Bypass -File .\VERIFY.ps1
# or by hand, then compare with SHA256SUMS.txt:
Get-FileHash .\W11-cleaner-tool-x64.exe -Algorithm SHA256

Requires Windows 11 Home or Pro, 64-bit. No administrator rights needed to start; the «Restart as administrator» button (Base and Expert mode) unlocks minidumps, restore points and system folders.

One step at a time, each tested on a real PC

Every feature that changes the system comes with a preview (before → after), a restore point (as administrator), a change log and undo where it is possible (not for cleaning and the Recycle Bin).

  4. ✓ 4
    Optimization

    Startup programs and power plan.

  5. ✓ 5

    Moved aside, never deleted straight away.
